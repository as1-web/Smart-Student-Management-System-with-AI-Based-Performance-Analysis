# Smart Student Management System with AI-Based Performance Analysis

## Overview

The Smart Student Management System is a GUI-based desktop application developed using Python. The project is designed to manage student records, attendance, academic performance, and AI-based performance analysis efficiently.

The system automates manual student management processes and provides intelligent academic suggestions through a rule-based AI mechanism. It also generates graphical reports for better understanding of student performance trends.

---

# Features

## Authentication System

* Admin Login
* Teacher Signup/Login
* Password Management
* User Block/Unblock System

## Student Management

* Add Student Records
* Manage Grades and Sections
* View Student Information
* Update Student Data

## Attendance Management

* Attendance Tracking
* Attendance Percentage Updates
* Attendance Monitoring

## Performance Analysis

* Subject-wise Marks Analysis
* Average Score Calculation
* Student Ranking System

## AI-Based Suggestions

* Weak Subject Detection
* Attendance Analysis
* Academic Improvement Suggestions
* AI-Generated Reports

## Data Visualization

* Performance Graphs
* Bar Charts
* Ranking Visualization

## CSV Import System

* Import Student Records from CSV Files
* Automatic Data Processing
